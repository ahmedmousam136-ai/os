1Download the template — one Excel file, one sheet for each kind of data. Fill only what you have.
📥 Excel template (.xlsx)
🛏 Bedsbed number, ward, rate per day
🩺 Admitted nowpatients in a bed today, with their bill and advance so far
👥 Patientsold patient list (register)
📋 Rate listyour charges: ICU, CBC, X-ray, doctor visit…
📦 Stockoxygen, gloves, medicines in store

Their own Excel works too, if the column names are close (“Bed No”, “Patient Name”, “Mobile”, “DOA”…). You will see a check before anything is saved. 🔒 Do not put Aadhaar numbers in the file — that column is never read.

2Choose the filled file — Excel (.xlsx / .xls) or CSV
3Import

Order: Beds → Rate list → Patients → Admitted now → Stock. Nothing is added twice: the same bed, the same patient (same old ID, or same name + phone) or the same item is updated or skipped. You can import the same file again safely.

Where does it show?
  • Beds → Bed Management (empty beds are green).
  • Admitted now → their bed turns occupied, Admissions, Billing. The bill shows “Bill before AuraScale” and “Advance paid before AuraScale” (minus), so the balance is right. New charges go on from today.
  • Patients → Patients (search by name, phone or old ID). Old ID is kept as the UHID.
  • Rate list → Reception → Add Charge → “From your rate list”: type ICU / CBC, the price fills by itself.
  • Stock → Stock.
  • Old PDFs / photos of a patient → open the patient → Documents → Upload.
